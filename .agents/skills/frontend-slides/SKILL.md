# Frontend Slides Skill

> Create web presentations without CSS/JavaScript knowledge. Uses a "show, don't tell" approach.

## Overview

- **Zero dependencies**: Single HTML files with inline CSS/JS
- **Visual style discovery**: Pick from generated previews
- **No npm or frameworks**: Pure HTML/CSS/JS

## Workflow

1. User provides content (slides, messages, images)
2. Generate visual style preview
3. User picks preferred direction
4. Create full presentation

## Included Styles

**Dark themes**: Bold Signal, Electric Studio, Creative Voltage, Dark Botanical
**Light themes**: Notebook Tabs, Pastel Geometry, Split Pastel, Vintage Editorial
**Specialty**: Neon Cyber, Terminal Green, Swiss Modern, Paper & Ink

## Slide Structure

```
- Title Slide
- Content Slides (text + images)
- Comparison Slides
- Results/Metrics Slides
- Conclusion Slide
```

## Technical Implementation

- Single HTML file with `<style>` block
- CSS animations for transitions
- Responsive design
- Print-friendly (optional)

## Usage

Invoke skill when user wants to create a presentation/slide deck for their project.
